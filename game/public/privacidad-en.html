Zoo Esponji · Privacy and terms of use

Last updated: 15 October 2026

In a nutshell

Zoo Esponji is a game for children. It does not ask for or store personal data: there is no sign-up and no need to type a name, and the game has no purchases, chat or social networks, and nobody can write anything inside it. It counts, anonymously, how much and how the game is played; you can turn that off in Settings. On Android it shows a rewarded ad from time to time, which can always be declined; the ads are served by Google, which receives some technical data about the device to do so (see “Advertising”). The web version has no ads. In the zoo there is a notice board where you can vote, anonymously, on the next idea to be added to the game.

What the game saves

Your game: the coins, the animals and enclosures you have unlocked, the pages of the book and the settings (music, sounds, joystick, stats and language). Also the first and the last day you played and how many times the game has been opened. So that nothing is counted twice, the device also keeps, only on the device, a small note of what has already been counted (today, this week and ever) and of the time played, and the notices still waiting to be sent; turning "Stats" off deletes the waiting notices. It also remembers what has been voted on the board and the last thing the board showed, to display it offline (no personal data). Everything is saved on your own device and is deleted when you uninstall the game or clear its data.

Anonymous statistics

To learn what players enjoy and where the game fails, the game sends notices about how it is used to a server owned by davidpladel: that it was opened, which screens are seen, which zoo animal is fed and with which food, which enclosures are visited, which pages of the book are read, what is bought in the in-game shop, how the board is used (whether it is opened, whether the QR code is seen and which option is voted for, without knowing who), and whether there was an error. These are always characters and objects from the game, never data about the player. It uses no cookies and no number that identifies the device or the person. To count how many people play, the device itself remembers whether it has already sent today's notice and does not send it again; that note never leaves the device.

If the game is played offline, the notices wait on the device and are sent when the connection returns; those that could not be sent within about a day are discarded the next time the game is opened. The internet address is shortened on arrival and is only used to know the country. The data is not shared with anyone, is not used for advertising and is deleted after 25 months at the latest. You can turn it off at any time with the "Stats" button in Settings; turning it off also deletes anything that was waiting.

Advertising

Only in the Android version. From time to time the game offers to watch an ad in exchange for in-game coins: at most one every 15 minutes of play and four a day, never when the game opens, and always with a button to say no. There is no other kind of ad.

The ads are served by Google AdMob. The game tells Google that it is directed to children and that it only accepts ads suitable for all audiences, so they are not personalised. The game does not use the device's advertising ID and does not ask for permission to use it. To show the ad and prevent fraud, Google receives the internet address (from which the approximate area is derived), technical data about the device and the app, how the ad is interacted with, and diagnostic data. Google handles that data under its own privacy policy: policies.google.com/privacy.

Votes and ideas

If the game is online, the notice board in the square asks our server (api.zooesponji.com) for the current vote and the ideas already chosen. When you vote, the vote, the option chosen and, if you change your vote, the previous option (so it can be subtracted) are sent. The vote is anonymous: our server does not store the IP address or anything that says who voted; it only adds up votes. The device remembers what has been voted so as not to vote twice. Ideas are not written in the game: they are sent from a separate web page (zooesponji.com/ideas), meant only for people over 18, which is reached with the code on the notice board. The names shown in the game (for example, “Lucía's idea”) were written by an adult on that website and we review them before publishing: first names or nicknames only.

Permissions

The game does not use the device's camera, microphone, location, contacts or photos. On Android it only uses the internet connection, for the anonymous statistics, the ads and the voting board, and it does not request the advertising ID permission. Google's ads component also declares technical permissions that give no access to your data: checking whether there is a connection, keeping the device awake while an ad plays, and working in the background.

Children

The game is designed for children aged 5 to 12 and can be played without giving any data. We do not ask for or store information that identifies minors. Ads in the Android version are requested from Google flagged as directed to children.

Your rights

Since the game does not collect personal data, we hold no data about you to look up, correct or delete; the anonymous statistics can be turned off in Settings. The board vote cannot be linked to anyone, so there is no data of yours to request or delete there. The board is not turned off in Settings: it only works when there is a connection. For the technical data Google handles when serving ads, see its policy (policies.google.com/privacy). Even so, if you have any question you can write to android@davidpladel.com, and you can always contact the Spanish Data Protection Agency (aepd.es).
